# Harbor_Portfolio

Harbor Kim's portfolio site: a small web app (Vite + React + Tailwind) copied from this Magic Patterns design:
https://www.magicpatterns.com/c/8d5e2husgc9vjxk5jtpt1y

- Site: https://harbor-k.github.io/Harbor_Portfolio/
- `src/` mirrors the design, so change it there rather than here.
- Every push to `main` rebuilds the site (`.github/workflows/deploy-pages.yml`).
- Images and videos load from the `harbor-pf` and `landing_page` repos, so keep those in place.
